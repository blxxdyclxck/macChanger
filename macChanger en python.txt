Este es un script cuyo objetivo es cambiar la MAC de una interfaz de red, solicitando al usuario tanto la interfaz de la MAC que queremos cambiar como la MAC nueva. Vamos a ir explicando por partes:


1.  import subprocess
Con import lo que hacemos es importar módulos para trabajar luego en el propio script, en este caso el módulo subprocess permite la ejecución de comandos del sistema desde python, aquí lo usaremos para ejecutar comandos de red


2.  interface = input("interface > ")
Aquí lo que hacemos es declarar la variable interface, la cual contiene una función input(esta se usa para recibir la entrada de un usuario por terminal) en este caso el mensaje de este input es interface > es decir se le pide al usuario que ingrese la interfaz que quiera cambiar y esta se almacenará en la variable interface.


3.  newMac = input("mac > ")
Igual que en la línea anterior en esta declaramos una variable que usa la función input pero en este caso lo que almacenamos no es la interfaz que el usuario quiere modificar si no la nueva MAC que se quiere usar.


4.  print("[+] Cambiando direccion MAC para " + interface +  " a " + newMac)
Con la función print lo que estamos haciendo es mostrar por pantalla al usuario un mensaje, el cual seria: [+] Cambiando direccion MAC para “interface” a “newMac” tanto interface como newMac varían segun lo que el usuario escriba por la interfaz ej: [+] Cambiando direccion MAC para eth0 a 00:11:22:33:44:55


5.  subprocess.call("ifconfig " + interface + " down", shell=True)
Como dijimos antes subprocess es un módulo de python que nos permite ejecutar comandos del sistema, con el .call lo que se consigue es que se espere a que termine este comando para continuar. la parte de "ifconfig " + interface + " down"  es el comando que ejecuta el subprocess, ifconfig sirve para gestión de interfaces de red, interface es la variable donde se nos guarda la interfaz a modificar y down es la orden que damos para desactivar esta interfaz y así poder modificarla. Esto lo hacemos así ya que la mayoría de las interfaces no nos permiten cambiar la MAC si están activas, este conjunto sería lo mismo que en terminal poner por ejemplo: 
  


La parte de shell=True lo que hace este argumento es indicar que se ejecutará en la terminal o shell del sistema, python ejecuta el comando como si lo escribieras directamente en terminal, esto es muy peligroso pues como explicaré más abajo esto abre un fallo de seguridad ya que nos permite la ejecución de código y al no estar protegido el código podemos inyectar otros comandos fácilmente.


6.  subprocess.call("ifconfig " + interface + " hw ether " + newMac, shell=True)
En esta línea hacemos casi lo mismo que en la anterior simplemente la variación es en que en vez de usar el argumento down usamos hw ether, hw(hardware) nos indica que queremos modificar un atributo de hardware de la interfaz de red, y ether nos indica que ese atributo que queremos cambiar es la direccion MAC.
  

La parte de newMac es la variable donde está almacenada la nueva dirección MAC que el usuario a introducido por ejemplo: 00:11:22:33:44:55; al final esta línea seria como poner en terminal:
  



7.  subprocess.call("ifconfig " + interface + " up", shell=True)
En esta línea nuevamente hacemos casi lo mismo que en las dos anteriores, en esta la única variación es que en vez de hacer down para desactivar la interfaz como en la primera línea con subprocess, en esta haremos up para volver a activar la interfaz ya que esta ya ha sido modificada.




IMPORTANTE: 
Este script no tiene en cuenta los privilegios del usuario que lo este lanzando es decir que si no tenemos privilegios de root no cambiara la MAC ya que el propio ifconfig no funciona sin privilegios:








  



  











Como mencione antes un  problema de este script es que si nos fijamos en el shell=True nos daremos cuenta de que podemos ejecutar comandos para los que no esta pensado este script veamos un ejemplo:


  



  











  



Como vemos se lleva a cabo sin problema, esto es malo ya que lo que hacemos es crear una vulnerabilidad y dar la posibilidad de hacer una ejecución de comandos no deseada.


  



Aquí lo que hacemos es en vez de usar una cadena de texto lo que estamos haciendo es pasar cada argumento por separado como elemento de una lista de esta manera python ejecuta sin pasar por una shell ya que al usar lista en vez de cadena de texto no es necesario procesar el texto en una shell, y además ejecuta directamente el binario del comando /sbin/ifconfig.
